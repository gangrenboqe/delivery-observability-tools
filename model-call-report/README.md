# 模型调用观测报表（model-call-report）

> 把本机 AI 网关留下的调用日志，变成一份能看懂、能汇报、能当证据的报表。

---

## 它回答四个问题

| 问题 | 看报表的哪一节 |
|---|---|
| 调了多少次？成功率多少？ | 一、总览 |
| **慢在哪？** | 二、耗时（P50 / P95 / **最长**） |
| 花了多少 token？ | 一、总览 |
| 失败都是什么原因？ | 三、失败原因 Top 10（**同类已归并**） |

---

## 快速开始

```bash
python llm_call_report.py                          # 用默认日志目录出报表
python llm_call_report.py --log-dir <日志目录>      # 指定目录
python llm_call_report.py --since 2026-10-01 --until 2026-10-11
python llm_call_report.py --json-only               # 只出 JSON
```

输出两个文件：

- `report.md` —— 人看（Markdown 表格）
- `summary.json` —— 机器读（可接后续看板/告警）

**依赖：无。**只用 Python 标准库（与主项目一致）。
测试用的也是标准库 `unittest`。

```bash
python -m unittest discover -s tests     # 22 项，全部纯函数，毫秒级
```

## 两个设计上花了心思的地方

### 1. 错误必须**归并**，否则报表是废的

排障时最花时间的不是看日志，是**从几千行里弄清到底有几种错**。

```
timeout after 123ms   ┐
timeout after 456ms   ├─→ timeout after Nms      （1 类，不是 2 行）
timeout after 7890ms  ┘
```

归并规则：先剥行首 `[N]`/`(N)`/`#N` 前缀 → 完整 UUID → `<uuid>`，长十六进制串 → `<id>`，
IP → `<ip>`，Windows 路径 → `<path>`，剩余数字 → `N`；空消息兜底「（无错误信息）」，截断 80 字符。

> 🔁 **跨工具统一（2026-10-11）**：这套规则与 `projects/log-triage` 的 `normalize()` 是**同一套**
> ——同一条错误在两个工具里必须归成同一类。**改这里必改那边。**

> ⚠️ **顺序有坑（实测踩过）**：必须**先掩码 ID，再折叠数字**。
> 反过来做的话，`8b1a01b6` 会先变成 `NbNaNbN`，十六进制正则再也匹配不上，归并就失效了。
> 这个问题是单元测试逼出来的，不是看代码看出来的。

### 2. 耗时**不要只看平均值**

平均值会被大量快调用拉低，**一次 30 秒的卡顿在平均值里几乎看不见**。

但也**别夸大 P95**：本项目实测跑出来的真实数据里，慢调用只占少数时，
P95 仍然是正常值——**真正的硬指标是最长耗时**（不受样本量影响）。

> 这两条是写测试时才发现的：一开始我在文档里写"P95 才是能报警的线"，
> 被一个反向测试证伪了（100 次里只有 1 次卡住，P95 什么也看不出来）。
> **所以文档改成了"P50/P95/最长一起看"。**

## 隐私

日志文件里含有**请求正文**（用户问了什么）。
本工具**只取**时间、状态码、耗时、token、错误类型，
**请求与响应正文一律不进报表，也不打印**。
单元测试里有一条断言专门守这条：`test_drops_request_body`。

---

## 实测结果（真实日志，不是样例数据）

在本机真实调用日志（50 条）上跑出来：

- 成功率 **64%**
- 耗时：最快 97ms / P50 6.7s / P95 115.7s / **最长 150.2s**
- token：入 1065 / 出 3564
- 失败 18 条，归并出 **5 类**原因（请求中止、限流执行超时、上游超时、模型测试超时…）

> 这份结果本身就是最好的证据：**它复现了我一直凭感觉说的"冷启动要十几秒"**，
> 而且给出了硬数字——最慢的一次 150 秒。

## 已知边界

- 只读日志，**不碰网关本身**，也不做实时监控（这是**离线报表**，不是 dashboard）
- 目前只适配 OmniRoute 的日志结构；换网关需要改 `load_calls()`
- 不做图表（Markdown 表格够用，图表是下一步）
